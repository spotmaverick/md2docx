### 关键结论（下次直接照做）

- **语言判定**：读 `GetUserDefaultUILanguage()` 的 LANGID，取主语言字段（`langid & 0x3FF`）
  与 `0x04`（LANG_CHINESE）比较 → zh，**其余一律 en**。不按国家/地区代码判定。
- **优先级**：`--lang` > `settings.json` 记忆档位 > 系统探测 > 兜底 `en`。
  「自动」本身也是一个会被持久化的档位。
- **切语言不重建窗口**，就地刷新全部可见文案（控件、表头、窗口标题、折叠区、提示条、进度、结果表）。
- 旧代码用 `info.endswith("成功")` 判断转换成功 —— 切英文立即失效（记为 **V-12**）。
  现改为结果行 iid 即 `Result` 下标，按行取对象。**逻辑不得依赖界面文案**已成硬约束。
- `RoundButton` 绝不能用 `self._w` / `self._h` 存尺寸：它们是 `tkinter.Misc` 的内部属性
  （控件 Tcl 路径名），覆盖后报 `_tkinter.TclError: invalid command name "134"`（**V-13**）。
  改用 `_bw` / `_bh`。短属性名做全局替换会连带改坏 `_hover` / `_worker` 等，必须按词边界复核。
- 输出文档正文里的中文（`[图片：alt]`、链接 `文字（URL）`）**不随界面语言变化**，
  由源 Markdown 决定；`check_i18n.py` 里以 `OUTPUT_CONTENT` 白名单显式豁免（遗留 G-07）。
