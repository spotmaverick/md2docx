# 2026-09-01

## Md2docs 工具开发

从零搭建了一个 Markdown 转 Word / WPS / TXT 的桌面工具，单文件 exe (15.21 MB)，双击打开浏览器界面。

### 技术栈
- 解析: markdown-it-py (CommonMark 兼容) + mdit-py-plugins/tasklists + BeautifulSoup
- DOCX: python-docx 原生生成
- DOC / WPS: 内置 RTF 引擎 (Word, WPS, LibreOffice 都能原生打开)
- TXT: 纯文本 + 任务列表 + 链接保留 URL
- 可选: win32com 调用本机 Word/WPS 生成二进制 .doc/.wps
- 界面: Python 内置 http.server + 浏览器 (无 tkinter / electron 依赖)
- 打包: PyInstaller 6.22, --onefile --windowed

### 关键设计
- 单进程 HTTP 服务 + 浏览器: 避免 GUI 框架的依赖与体积
- 文件/目录选择走服务端 API (/api/browse)，前端只展示
- 拖拽上传走 JSON 文本上传 (无需 multipart 解析)
- 退出: UI 按钮 / 长时间无心跳 (10 分钟) -> os._exit(0) 兜底
- CLI 模式: GUI 打包也能用，Windows AttachConsole(-1) 附着到父控制台

### 环境坑
- 机器全局 PYTHONHOME 干扰 venv python
  需 env -u PYTHONHOME -u PYTHONPATH 才可正常调用 pip / python

## 第二轮：用户反馈四问题修复
1. **输出目录不生效**：前端选完目录后 outMode 单选仍停在"与源文件相同"。修复：confirmBrowse 选目录后自动切到 custom。
2. **移除下载功能**：删掉 /api/download 接口与前端"下载"按钮，改为"打开所在文件夹"(/api/open)。
3. **标题颜色**：theme.py 重写为 GitHub 风格配色（标题=正文色 24292F，仅字号/字重区分）。**坑**：重写时漏了 MONO_FONT 常量，docx_writer 引用崩 AttributeError——改 theme 后必须 grep 全部 theme.XXX 引用核对。
4. **WPS 检测失败**：pythoncom 没有 ProgIDFromString 这个 API（写错了被静默吞掉）。正确做法：pythoncom.CLSIDFromProgID + winreg 查 HKCR\<ProgID>\CLSID 兜底。本机 WPS ProgID 为 KWPS.Application。

### PyInstaller onefile 退出挂死（重要环境坑）
- 现象：exe（--onefile --noconsole）子进程退出后，bootloader 父进程永远挂死，_MEI 临时目录残留。最小复现程序同样挂，与业务代码无关（PyInstaller 6.22.2 / Win10 19045）。
- 解法：app.py 退出前 `_cleanup_frozen_exit()`——用 Toolhelp 快照拿父 PID，确认同名 exe 后 TerminateProcess 结束父进程；再起分离 cmd 任务 (ping 延时 + rd /s /q) 清理 sys._MEIPASS。
- 验证：quit 后 1 秒退出，无进程残留，_MEI 目录被清理；CLI 模式同样干净。
- 打包被占用会 PermissionError：先 Get-Process Md2docs | Stop-Process -Force 再打包。
- 本会话 PowerShell 工具输出通道异常（无回显），但命令实际执行；bash 的 rm -rf 会被沙箱 safe-delete 拦截且无提示，删目录用 python shutil 或 PowerShell 单条命令。
