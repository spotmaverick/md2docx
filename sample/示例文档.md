# 项目周报（示例）

> 这是一份用于演示 **Md2docs** 转换效果的 Markdown 示例文档。
> 它覆盖了标题、列表、表格、代码、引用、链接等常见语法。

## 一、本周进展

1. 完成了 **Markdown 解析层**，支持 GFM 表格与围栏代码块
2. 实现了三种渲染后端
   - DOCX：原生 Word 格式，`python-docx` 生成
   - DOC / WPS：内置 RTF 引擎，Word、WPS、LibreOffice 均可直接打开
   - TXT：可去掉 Markdown 符号，输出易读纯文本
3. 打通了界面与批量转换流程
   - 支持拖拽添加
   - 支持多选文件与批量输出

## 二、关键指标

| 指标 | 上周 | 本周 | 变化 |
| --- | --- | --- | --- |
| 转换成功率 | 92.1% | **99.3%** | +7.2% |
| 平均耗时 | 820 ms | 165 ms | -79.9% |
| 支持格式数 | 2 | 4 | +2 |

## 三、代码示例

```python
from convert import convert_file

results = convert_file("报告.md", formats=["docx", "txt"])
for r in results:
    print(r.target, r.engine)
```

行内代码也很常见，比如 `markdown.markdown(text, extensions=["tables"])` 这句。
